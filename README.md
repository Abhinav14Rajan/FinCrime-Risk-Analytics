\# FinCrime Risk Analytics



An end-to-end Financial Crime Risk Analytics project using \*\*MySQL, Python, Microsoft Excel, and Power BI\*\* to explore customer risk, transaction activity, KYC records, and fraud-related alerts.



\## Project Overview



This project demonstrates how data analytics can support financial crime risk monitoring and investigation. It combines SQL-based data analysis, Python data exploration, Excel reporting, and interactive Power BI dashboards.



All datasets used in this project are synthetic and created for learning and demonstration purposes.



\## Business Objectives



\- Analyze customer and transaction data.

\- Identify high-risk customers using risk indicators.

\- Monitor failed transaction activity.

\- Explore KYC records and risk factors.

\- Analyze alerts to support risk monitoring.

\- Present key findings through interactive dashboards.

\## How to Use



1\. Clone or download this repository.

2\. Import the SQL dump from the `SQL` folder into MySQL.

3\. Open the Jupyter Notebook from the `Python` folder.

4\. Open the Excel workbook from the `Excel` folder.

5\. Open the Power BI report from the `PowerBI` folder.



Update database connection settings in the notebook if required.
